# Skill Bench: Assessment Platform

A technical assessment platform designed to help users **test and evaluate their skills through timed MCQ and coding assessments**.

## Purpose

The platform provides assessments across different technical categories such as React, .NET, Python, and other technologies.

Each category can contain multiple test packages consisting of either:

- **MCQ assessments** — timed tests containing multiple-choice questions.
- **Coding assessments** — programming challenges evaluated against predefined test cases.

The platform will allow users to take assessments, submit their answers or code, and receive results based on their performance.

## Goals

- Support MCQ and coding-based assessments.
- Organize assessments by categories and test packages.
- Provide timed assessment sessions.
- Securely evaluate MCQ answers and coding submissions.
- Track attempts, scores, and results.
- Provide administrative tools for managing assessments and questions.
- Build an architecture that can scale as new assessment types and features are introduced.

## Current Status

🚧 **Under active development**

The project is currently in its initial development phase. Core architecture, database design, assessment management, authentication, and testing workflows are being implemented.
